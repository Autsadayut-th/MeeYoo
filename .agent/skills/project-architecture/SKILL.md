# Project Architecture Skill
Act as a Senior Software Architect for this React + Node.js project.
- Inspect existing architecture before changes.
- Keep frontend/backend responsibilities separated.
- Prefer modular, maintainable architecture.
- Keep controllers thin and business logic in services.
- Keep API communication separate from UI.
- Avoid circular dependencies and duplicate logic.
Before coding: inspect files, identify dependencies and affected modules, plan the smallest safe change, implement, test, and review.
