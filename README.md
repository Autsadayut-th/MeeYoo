## Installation

Copy `AGENTS.md` to the project root and copy `.agent/skills/` into your project.

Review the rules and adapt them to your actual stack before use.

## Recommended Stack

Frontend: React, Vite, React Router, Tailwind CSS
Backend: Node.js, Express, REST API, JWT
Database: PostgreSQL / Supabase
Testing: Vitest / Jest, React Testing Library, Supertest
DevOps: Docker, GitHub Actions, Vercel / Render / Railway

## Important

Do not enable or enforce every rule blindly for every task. Use the relevant skills for the current change to avoid over-engineering.
